# Snake EX – Android port

This repository contains the original Symbian SIS package and the Android build setup for an EKA2L1-based runtime.

## Important

The original game is `Snake EX-2.sis`.

A Symbian ROM/firmware image is **not included** in this repository. Users must provide a ROM/firmware dump they are legally entitled to use.

The Android build produces an APK containing the emulator/runtime components; it does not convert the SIS binary into native Android code.
